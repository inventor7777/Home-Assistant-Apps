# Home Assistant Apps

| App | Description |
| --- | --- |
| [vnStat](vnstat/README.md) | Persistent network traffic monitoring with an ingress dashboard and CLI. |
| [State Sync](state_sync/README.md) | Maintain desired entity states with entity/time syncs, conditions, priorities, and snoozes. Experimental. |

## Install

[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Finventor7777%2FHome-Assistant-Apps)

Or add `https://github.com/inventor7777/Home-Assistant-Apps` in **Settings → Apps → App store → Repositories**.
Supervisor builds both containers locally; no registry account is required. Installation needs internet access for the base images and Alpine packages.
